# بوبو لاند 🎮

تطبيق ألعاب للأطفال. بيشتغل عالجوال والكمبيوتر، بدون إعلانات، وبدون إنترنت بعد أول فتحة، وبيتثبّت عالشاشة الرئيسية متل التطبيق.

## الألعاب
| اللعبة | اللاعبين | الفكرة |
|---|---|---|
| 🏠 **بيت بوبو** (`bobo/`) | ١ | اجمع المفاتيح، تخبّى بالصناديق، واهرب من بوبو. ٦ مراحل ونجوم (آخر مرحلة قبو معتم). |
| 🎉 **حفلة الأصحاب** (`party/`) | ٢–٤ على نفس الجوال | ألعاب صغيرة: مين الأسرع ⚡، سباق الكبس 🏁، أرض الحمم 🌋، شد الحبل 🪢. أول واحد بيجمع النقاط بيربح. |
| 👤 **ألعاب بوبو** (`solo/`) | ١ | ١٢ لعبة: الذاكرة، صيد الحروف، حساب بوبو، فقاعات الألوان، قفز بوبو، بوبو الراكض، برج المكعبات، صيد السمك، البازل، الأشكال، لقط الفواكه، وين بوبو؟ |
| ⚔️ **تحدّي الاثنين** (`duel/`) | ٢ (واحد تحت وواحد فوق) | ٢٢ لعبة: حجرة ورقة مقص، البولينغ، نفخ البالون، الرماية، مين أسرع بالحساب، إكس أو، تنس الطاولة، كرة القدم، البلياردو، السلة، الأفعى، سباق السيارات، حرب الألوان، دفّش برّا، الأسهم والجذع، ضو أحمر ضو أخضر، ضربة الكف، جمع المصاري، تقطيع الفواكه، العصفور الطاير، الحطّاب، شد الحبل. اللي بيربح ٣ جولات بياخد الكاس. |

## اللغات 🌐
التطبيق بيحكي **عربي، إنجليزي، وتركي**. بيختار لحاله حسب لغة الجوال (وأي لغة تانية بتطلع إنجليزي)، وفي زر 🌐 بالشاشة الرئيسية لتغييرها.
- الملف `i18n.js` بيعمل كل شي: بالكود `L('عربي', 'English', 'Türkçe')`، وبالـ HTML `data-en` / `data-tr`.
- صفحات المتجر: `store/listing.md` (عربي)، `store/listing-en.md`، `store/listing-tr.md`، والصور بـ `store/`، `store/en/`، `store/tr/`.
- بـ Google Play Console: ضيف ترجمة للمتجر (Store listing → Manage translations) للإنجليزي والتركي، وحط النص والصور من هالملفات.

## ليش الولد بيرجع يلعب
- 🪙 **عملات:** كل مرحلة أو مباراة بتعطي عملات (`world.js`).
- 👕 **خزانة بوبو:** ألوان وقبعات ونضارات بتنشرى بالعملات، وبوبو بيطلع فيها جوّا اللعبة.
- 🎁 **هدية كل يوم:** بتكبر لـ ٧ أيام ورا بعض.
- 🏅 **ألبوم ملصقات:** ١٦ ملصق بتنفتح بالإنجازات.
- ⭐ **أحسن نتيجة** محفوظة بكل لعبة.
- 💾 **رمز الحفظ:** بينسخ كل التقدم لجوال تاني بدون حساب.

## النشر المجاني على GitHub Pages
1. ادمج الفرع بـ `main`.
2. بالمستودع: **Settings ← Pages**.
3. تحت **Branch** اختار `main` و `/ (root)` واكبس **Save**.
4. بعد دقيقة بيصير الرابط: `https://animosalaya-maker.github.io/kids-games/`

## التثبيت عالجوال
افتح الرابط بكروم، ومن القائمة ⋮ اختار **إضافة إلى الشاشة الرئيسية**.

## النشر على Google Play
1. فعّل GitHub Pages (فوق) وتأكد إنه الرابط شغّال.
2. افتح **pwabuilder.com**، حط الرابط، واكبس **Package for stores ← Android**، ونزّل الملف `.aab`.
3. بـ **Google Play Console** (اشتراك لمرة وحدة ٢٥$) اعمل تطبيق جديد وارفع الملف.
4. نص صفحة المتجر والصور جاهزين بمجلد `store/` (`store/listing.md`).
5. سياسة الخصوصية: `privacy.html`.
6. PWABuilder بيعطيك ملف `assetlinks.json`: حطه بمجلد `.well-known/` بهالمستودع لحتى يختفي شريط المتصفح من التطبيق.

## النشر على آبل (App Store) بدون ماك 🍎
البناء بيصير على ماك عند GitHub (ملف `.github/workflows/ios-release.yml`)، متل تطبيق سهل.
1. **App Store Connect** ← التطبيقات ← **+** ← تطبيق جديد: الاسم `Bobo Land`، اللغة عربي، Bundle ID: `com.boboland.kids`، SKU: `boboland`.
2. **مفاتيح آبل** بهالمستودع: Settings ← Secrets and variables ← Actions ← New repository secret، وحط الأربعة (نفس قيم مستودع سهل):
   `APPSTORE_ISSUER_ID`، `APPSTORE_KEY_ID`، `APPSTORE_KEY_P8`، `APPLE_TEAM_ID`.
3. **Actions** ← ios-release ← Run workflow. بعد حوالي ١٥ دقيقة بتوصل النسخة على **TestFlight**.
4. من App Store Connect: الصور والوصف (نفس ملفات `store/`)، والخصوصية، والفئة العمرية، وبعدين **إرسال للمراجعة**.
